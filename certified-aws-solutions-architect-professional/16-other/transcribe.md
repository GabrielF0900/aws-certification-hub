# Amazon Transcribe

- É um serviço de Reconhecimento Automático de Fala (ASR - Automatic Speech Recognition)
- Entrada (Input): áudio; saída (output): texto
- Oferece vários recursos que melhoram essa funcionalidade:
    - Personalizações de idioma (Language customizations)
    - Filtros para privacidade
    - Idioma apropriado para o público (Audience-appropriate language)
    - Identificação do locutor (Speaker identification)
- Além disso, podemos configurar vocabulários personalizados e configurar modelos de linguagem de acordo com nosso caso de uso
- O produto é pago conforme o uso por segundo de áudio transcrito
- Os produtos vêm em sabores (flavors) diferentes, como Transcribe, Transcribe Medical e Transcribe Call Analytics
- Casos de uso do Amazon Transcribe:
    - Indexação de texto completo de áudio para permitir a pesquisa
    - Criar notas de reunião
    - Gerar legendas (subtitles/captions) e transcrições
    - Com o Call Analytics, podemos ingerir chamadas telefônicas para fazer análises, como características, sumarização, categorias e análise de sentimento
- Pode ser integrado com nossos aplicativos via APIs, bem como se integra com outros serviços de ML da AWS

# Amazon Transcribe

- Is an Automatic Speech Recognition (ASR) service
- Input: audio; output: text
- Offers various features that improve this feature:
    - Language customizations
    - Filters for privacy
    - Audience-appropriate language
    - Speaker identification
- In addition we can configure custom vocabularies and configure language models according to our use-case
- The product is pay as we use per second of transcribed audio
- Products comes in different flavors such as Transcribe, Transcribe Medical and Transcribe Call Analytics
- Amazon Transcribe use cases:
    - Full text indexing of audio to allow searching
    - Create meeting notes
    - Generate subtitles/captions and transcripts
    - With Call Analytics we can ingest phone calls to do analytics such as characteristics, summarization, categories and sentiment analysis
- Can be integrated with our applications with APIs as well it integrates with other AWS ML services
