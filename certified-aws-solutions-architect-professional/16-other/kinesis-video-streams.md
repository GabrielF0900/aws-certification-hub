# Kinesis Video Streams

- Permite-nos ingerir dados de vídeo ao vivo (live video data) de produtores
- Os produtores podem ser câmeras de segurança, smartphones, carros, drones, dados de áudio serializados no tempo, dados térmicos, de profundidade e de RADAR
- Os consumidores podem acessar os dados quadro a quadro (frame-by-frame) ou conforme necessário
- O Kinesis pode persistir e criptografar dados em trânsito e em repouso (at rest)
- Não podemos acessar os dados diretamente via armazenamento, apenas via APIs!
- Os dados não são armazenados em seu formato original. Os dados são indexados e armazenados de forma estruturada
- O Kinesis Video Streams integra-se com outros serviços da AWS, como o Rekognition e o Connect

# Kinesis Video Streams

- Allows us to ingest live video data from producers
- Producers can be security cameras, smartphones, cars, drones, time-serialised audio, thermal, depth and RADAR data
- Consumers can access the data frame-by-frame or as needed
- Kinesis can persist and encrypt data in-transit and at rest
- We can not access data directly via storage, only via APIs!
- Data is not stored in its original format. Data is indexed and stored in a structured way
- Kinesis Video Streams integrates with other AWS services such as Rekognition and Connect
