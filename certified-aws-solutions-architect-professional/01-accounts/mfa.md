# Autenticação Multifator (MFA)

- **Fator**: uma peça diferente de evidência que prova a identidade
- Fatores:
    - **Conhecimento**: algo que sabemos como usuários: nome de usuário, senha
    - **Posse**: algo que temos como usuários: cartão bancário, dispositivo/app MFA
    - **Inerente**: algo que somos, exemplos: impressão digital, rosto, voz, íris
    - **Localização**: uma localização (física) ou qual rede estamos conectados (wifi corporativo)
- Mais fatores significam mais segurança, mais difícil de contornar por um invasor

# Multi-Factor Authentication (MFA)

- **Factor**: different piece of evidence which proves the identity
- Factors:
    - **Knowledge**: something we as users know: username, password
    - **Possession**: something we as users have: bank card, MFA device/app
    - **Inherent**: something we are, example: fingerprint, face, voice, iris
    - **Location**: a location (physical) or which network we are connected to (corporate wifi)
- More factors means more security, harder to bypass by an intruder
