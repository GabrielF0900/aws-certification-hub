# ⚡ Início Rápido - Translation Script

## 🚀 Executar em 30 Segundos

### Windows
```bash
cd translation-script
run_translator.bat
```

### Linux / Mac
```bash
cd translation-script
bash run_translator.sh
```

---

## 📋 O que o Script Faz

1. ✅ Verifica dependências Python
2. ✅ Instala/atualiza `googletrans`
3. ✅ Busca todos os arquivos `.md` não traduzidos
4. ✅ Traduz para português automaticamente
5. ✅ Mantém português no topo, inglês embaixo (separados por `---`)
6. ✅ Registra progresso em `translation_log.json`

---

## 📊 Estrutura de Saída

**Antes:**
```markdown
# Title

Content in English
```

**Depois:**
```markdown
# Título

Conteúdo traduzido para português

---

# Title

Content in English
```

## 🔧 Se der Erro

### "ModuleNotFoundError: No module named 'googletrans'"

```bash
pip install googletrans==4.0.0
python translate_all.py
```

### "Translation API Error"

- Aguarde 5 minutos (Google Translate rate-limiting)
- Execute novamente: `python translate_all.py`
- O script continuará de onde parou
