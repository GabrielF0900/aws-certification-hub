# 🌍 Tradutor Automático - AWS Solutions Architect Professional

Script Python para traduzir automaticamente todos os arquivos markdown do projeto para português, mantendo a tradução em português no topo e o original em inglês embaixo.

## 📋 Requisitos

- Python 3.7+
- pip (gerenciador de pacotes Python)

## 🚀 Como Usar

### 1. Instalar Dependências

```bash
# Navegar até a pasta do script
cd translation-script

# Instalar pacotes necessários
pip install -r requirements.txt
```

### 2. Executar o Script

```bash
# Do diretório translation-script
python translate_all.py

# Ou do diretório raiz do projeto
python translation-script/translate_all.py
```

### 3. Monitorar Progresso

O script exibirá:
- Lista de arquivos sendo traduzidos
- Status de cada tradução (✅ Done, ⏭️ Already translated, ❌ Error)
- Resumo final com estatísticas

## ✨ Funcionalidades

- ✅ **Tradução Automática**: Usa Google Translate para traduzir conteúdo
- ✅ **Preservação de Estrutura**: Mantém formatação markdown intacta
- ✅ **Rastreamento de Progresso**: Log JSON com arquivos traduzidos
- ✅ **Evita Re-tradução**: Detecta arquivos já processados
- ✅ **Rate Limiting**: Respeita limites da API
- ✅ **Tratamento de Erros**: Continua em caso de erros pontuais
- ✅ **Resumo Detalhado**: Estatísticas ao final da execução

## 🔧 Formato de Saída

Cada arquivo .md será reformatado assim:

```markdown
# Título em Português

- Conteúdo traduzido em português
- Mantém estrutura original

---

# Título Original em Inglês

- Original content in English
- Preserves original structure
```

## 📝 Notas Importantes

1. **Não Traduz**:
   - Código dentro de blocos ` ``` `
   - URLs e links
   - Imagens
   - Acrônimos AWS (IAM, EC2, VPC, etc.)
   - Linhas vazias

2. **Comportamento**:
   - Cada linha é traduzida individualmente mantendo estrutura
   - Aguarda 1 segundo entre arquivos para evitar rate-limiting
   - Cria backup automático do arquivo original (mantém como comentário na tradução)

3. **Primeira Execução**:
   - A primeira execução pode levar tempo (115 arquivos × ~3 segundos)
   - Tempo estimado: **5-10 minutos**
   - Evite interrupções bruscas (Ctrl+C)

## 🔄 Continuar de Onde Parou

Se o script for interrompido, ele pode ser executado novamente:

```bash
python translate_all.py
```

O script verificará `translation_log.json` e continuará de onde parou.

## 🛠️ Troubleshooting

### Erro: "ModuleNotFoundError: No module named 'googletrans'"

```bash
# Reinstalar dependências
pip install --upgrade googletrans
```

### Erro: "Translation API Error"

- Pode ser rate-limiting temporário do Google Translate
- Aguarde alguns minutos e execute novamente

### Erro de Encoding

- Garanta que Python está configurado para UTF-8:

```bash
# Windows
set PYTHONIOENCODING=utf-8

# Linux/Mac
export PYTHONIOENCODING=utf-8
```
