## AWS App Runner

- Serviço totalmente gerenciado para implantação de aplicativos conteinerizados e APIs
- É uma solução PaaS com todos os componentes gerenciados pela AWS - nós apenas trazemos nosso código e imagem de contêiner
- Integra-se com o GitHub e o ECR para obter código ou contêineres já criados
- Fornece os seguintes recursos:
    - Auto scaling (Escalonamento automático)
    - Load balancing (Balanceamento de carga)
    - Health checks (Verificações de integridade)
    - Observabilidade
- Aplicações do App Runner podem rodar dentro de uma VPC

## AWS App Runner

- Fully managed service for deploying a containerized apps and APIs
- It is a PaaS solution with all components managed by AWS - we just bring our code and container image
- Integrates with GitHub and ECR for getting code or already built containers
- Provides the following features:
    - Auto scaling
    - Load balancing
    - Health checks
    - Observability
- App Runner applications can run inside in a VPC
