# Amazon Mechanical Turk

- Fornece um sistema gerenciado de terceirização de tarefas humanas
- Fornece um conjunto de APIs e um marketplace (mercado) para terceirizar trabalhos para seres humanos
- Permite que os solicitantes publiquem Tarefas de Inteligência Humana (Human Intelligence Tasks - HITs) num marketplace
- As tarefas são concluídas por trabalhadores (workers), que ganham dinheiro por isso
- Pagamento por tarefa, ideal para tarefas que são mais adequadas para humanos do que para Machine Learning (ML)
- Qualificação: atributo do trabalhador; podemos exigir um teste. Uma qualificação pode ser um requisito para concluir HITs
- Ótimo para coleta de dados, processamento manual, classificação de imagens

# Amazon Mechanical Turk

- Provides a managed human task outsourcing system
- Provides a set of APIs and a marketplace to outsource jobs to human beings
- Allows requesters to post Human Intelligence Tasks (HITs) to a marketplace
- Tasks are completed by workers, who earn money for it
- Pay per task, perfect for tasks suited to humans rather than ML
- Qualification: worker attribute, we can require a test. A qualification can be a requirement to complete HITs
- Great for data collection, manual processing, image classification
