# 📍 Onde Paramos — Status das Traduções

## 📋 Como é feita a tradução

O método de tradução segue um padrão específico ensinado pelo usuário:

1. **Tradução em Português no topo** — o conteúdo completo traduzido para português aparece primeiro
2. **Separador `---`** — uma linha horizontal separando os dois idiomas
3. **Conteúdo original em Inglês embaixo** — o texto original é mantido integralmente abaixo

### Exemplo do formato:
```
# Título em Português

- Conteúdo traduzido...

---

# Title in English

- Original content...
```

> **Regra importante:** A tradução é literal e completa — nada é resumido ou omitido. Todo o conteúdo original é preservado na seção em inglês, e a versão portuguesa é uma tradução fiel, sem resumos.
