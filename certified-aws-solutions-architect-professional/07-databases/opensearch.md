# AWS OpenSearch (Anteriormente conhecido como ElasticSearch)

- É uma implementação gerenciada do ElasticSearch, uma solução de pesquisa de código aberto. Faz parte do stack ELK (ElasticSearch, Logstash, Kibana)
- O OpenSearch não é serverless; é executado em uma VPC usando computação
- O OpenSearch é geralmente uma alternativa a outros serviços AWS
- Pode ser usado para análise de logs, monitoramento, análise de segurança, pesquisa e indexação de texto completo, análise de fluxo de cliques

## Stack ELK

- ElasticSearch (ou OpenSearch na AWS): fornece serviços de pesquisa e indexação
- Kibana: ferramenta de visualização e dashboard
- Logstash: semelhante ao CloudWatch Logs; requer um agente Logstash instalado em qualquer coisa para ingestão de dados

# AWS OpenSearch (Formerly known as ElasticSearch)

- Is a managed implementation of ElasticSearch, an open source search solution. It is part of the ELK stack (ElasticSearch, Logstash, Kibana)
- OpenSearch is not serverless, it runs in a VPC using compute
- OpenSearch is usually an alternative to other AWS services
- Can be used for log analytics, monitoring, security analytics, full text search and indexing, click stream analytics

## ELK Stack

- ElasticSearch (or OpenSearch on AWS): provides search and indexing services
- Kibana: visualization and dashboard tool
- Logstash: similar to CloudWatch Logs, needs a Logstash agent installed on anything to ingest data
