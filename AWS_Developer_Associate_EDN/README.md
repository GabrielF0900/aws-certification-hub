# AWS Certified Developer – Associate | Escola da Nuvem

Repositório de estudos para a certificação AWS Certified Developer – Associate, organizado por domínio e tipo de material.

## Organização

- `01_Dominio_1_Desenvolvimento_AWS/` — desenvolvimento com serviços AWS.
- `02_Dominio_2_Seguranca/` — segurança.
- `03_Dominio_3_Deployment/` — implantação.
- `04_Dominio_4_Troubleshooting_e_Optimizacao/` — solução de problemas e otimização.

Cada domínio contém pastas para laboratórios documentados em Word, materiais teóricos em PDF e simulados/questões. Os arquivos `README.md` nas pastas explicam o conteúdo esperado; eles também permitem que o GitHub exiba pastas inicialmente vazias.
