## 🚦 Trilhas de Aprendizado Recomendadas

### 1️⃣ **Trilha Iniciante** (0-3 meses)
Ideal para quem está começando em cloud.

**Sequência:**
1. **Módulos Re_Start (01-06)** → Cloud Foundations, Redes, Segurança, Bases, Arquitetura, Operações
2. **Laboratorios (01-07)** → EC2, VPC, IAM, CLI, S3 website, Escala
3. **Simulados_65_Questoes** (Pré-teste) → Diagnóstico inicial
4. **Revisão com Anki** → 10 min/dia com flashcards
5. **Meus Simulados** → Tópicos IAM & Infraestrutura

**Tempo estimado:** 4-8 semanas (dedicado 5+ horas/semana)

### 2️⃣ **Trilha Cloud Practitioner** (1-4 meses)
Preparação específica para certificação **CLF-C02**.

**Sequência:**
1. **Módulos Re_Start (completo: 01-18)** → Todos os módulos progressivamente
2. **Laboratorios (completo: 01-14)** → Todos os 14 labs, consolidando cada domínio
3. **Meus Simulados (revisão temática)** → Todos os 15 questionários
4. **Simulados_65_Questoes (simulados completos)** → Pré-teste, Simulados 01-02, Quiz, Revisão
5. **Simulados do Maik (últimas 2 semanas)** → 4 simulados práticos
6. **Revisão com Anki** → Deck: AWS Cloud Practitioner - CLF-C02 (440 cards) | 5-10 min/dia
7. **Currículo (paralelo)** → Preparar perfil profissional enquanto estuda

**Tempo estimado:** 6-10 semanas (dedicado 5+ horas/semana)

### 3️⃣ **Trilha Solutions Architect Associate** (3-6 meses)
Evolução para **SAA-C03** após dominar Cloud Practitioner.

**Pré-requisito:** Concluir Cloud Practitioner

**Sequência:**
1. **Módulos Re_Start (07-18)** → Ferramentas, Servidores, Escala, Serverless, Bancos, Redes, Armazenamento, Monitoramento, Gerenciamento, IaC
2. **Laboratorios (08-14)** → Labs avançados (Serverless, RDS, VPC, EBS/S3, Monitoramento, IaC)
3. **Projetos Treinamento** → Projetos para aplicar arquitetura
4. **Meus Simulados (tópicos avançados)** → RDS/DynamoDB, HA/Confiabilidade, Segurança Avançado, Simulados Difíceis
5. **Revisão com Anki** → Deck: AWS Solution Architect Associate - SAA-C03 (327 cards)

**Tempo estimado:** 8-12 semanas (dedicado 5+ horas/semana)

## 💡 Dicas para Sucesso

1. **Consistência > Intensidade**
   - 1-2 horas diárias é melhor que 10 horas no fim de semana

2. **Prática é essencial**
   - Não só leia: faça cada lab, cada simulado

3. **Anki funciona**
   - Dedique 10 min diários. Transformador para retenção.

4. **Aprenda o "porquê"**
   - Não decore respostas. Entenda arquitetura e trade-offs.

5. **Tenha um projeto real**
   - Estude enquanto trabalha em algo prático (mesmo pessoal)

6. **Comunidade é poder**
   - Não estude sozinho. Encontre grupos de estudo.

## ❓ Dúvidas Frequentes

**P: Por onde começo?**
R: Se é iniciante total, faça a "Trilha Iniciante". Se já tem noções, pule para "Trilha Cloud Practitioner".

**P: Quanto tempo leva?**
R: Trilha Iniciante: 4-8 semanas. Cloud Practitioner: 6-10 semanas. Solutions Architect: 8-12 semanas.

**P: Preciso fazer os labs?**
R: SIM. São 70% do aprendizado efetivo. Prática hands-on é essencial.

**P: Qual certificação escolher primeiro?**
R: Cloud Practitioner (CLF-C02) é a base sólida. Depois Solutions Architect (SAA-C03).

**P: Todos os simulados são necessários?**
R: Não, mas ter múltiplas perspectivas aumenta suas chances. Mínimo: 1 simulado temático + 2 completos + Maik na reta final.

**P: Posso estudar enquanto trabalho?**
R: Sim. 1-2 horas diárias é suficiente. Consistência > intensidade.

**P: E depois de certificado?**
R: Atualize LinkedIn, busque oportunidades, considere próxima especialização.
