## 🚦 Trilhas de Aprendizado Recomendadas

### 1️⃣ **Trilha Iniciante** (0-3 meses)
Ideal para quem está começando em cloud.

**Sequência:**
1. [**Módulos Re_Start (01-06)**](./Modulos%20Re_Start/README.md)
   - 01: Cloud Foundations
   - 02: Redes
   - 03: Segurança
   - 04: Bases
   - 05: Arquitetura AWS
   - 06: Operações

2. [**Laboratorios (01-07)**](./Laboratorios/README.md)
   - Introdução a EC2
   - Criar VPC
   - IAM na prática
   - Banco de dados básico
   - CLI da AWS
   - Website em S3
   - Escala e resolução de nomes

3. [**Simulados_65_Questoes** (Pré-teste)](./Simulados_65_Questoes/README.md)
   - Pré-teste oficial AWS
   - Simulado 01 (nivelamento)

4. **Revisão com Anki**
   - Usar deck: `AWS Cloud Practitioner - CLF-C02 (440 cards).apkg`

### 2️⃣ **Trilha Cloud Practitioner** (1-4 meses)
Preparação específica para certificação **CLF-C02**.

**Sequência:**
1. [**Módulos Re_Start (completo: 01-18)**](./Modulos%20Re_Start/README.md)
   - Cobrindo todos os 18 módulos progressivamente

2. [**Laboratorios (completo: 01-14)**](./Laboratorios/README.md)
   - Todos os 14 labs, consolidando cada domínio

3. [**Meus Simulados** (revisão temática)](./Meus%20Simulados/README.md)
   - Questionário de Infraestrutura
   - Questionário de Serviços
   - Questionário de Contêineres
   - Questionário de Preço
   - Simulados por tópico (RDS, DynamoDB, Segurança)

4. [**Simulados_65_Questoes** (simulados completos)](./Simulados_65_Questoes/README.md)
   - Pré-teste oficial
   - Simulado 01, 02 (do livro)
   - Quiz de revisão
   - Revisão 224 Wayground

5. [**Simulados do Maik** (últimas 2 semanas)](./Simulados%20do%20Maik/README.md)
   - 4 simulados práticos
   - Foco em erros comuns

6. **Revisão com Anki**
   - Deck: `AWS Cloud Practitioner - CLF-C02 (440 cards).apkg`
   - Revisar 5-10 minutos por dia

7. [**Currículo** (paralelo)](./Curriculo/README.md)
   - Preparar perfil profissional enquanto estuda

**Tempo estimado:** 4-8 semanas (dedicado 5+ horas/semana)

### 3️⃣ **Trilha Solutions Architect Associate** (3-6 meses)
Evolução para **SAA-C03** após dominar Cloud Practitioner.

**Pré-requisito:** Concluir Cloud Practitioner

**Sequência:**
1. [**Módulos Re_Start (07-18)**](./Modulos%20Re_Start/README.md)
   - 07: Ferramentas e Automação
   - 08-18: Tópicos avançados (Servidores, Escala, Serverless, Bancos, Redes, Armazenamento, Monitoramento, Gerenciamento, Implantação Automática)

2. [**Laboratorios (08-14)**](./Laboratorios/README.md)
   - Foco em labs avançados:
   - Serverless e Contêineres
   - Serviços de Banco de Dados
   - Serviços de Redes
   - Armazenamento e Arquivamento
   - Monitoramento e Segurança
   - Implantação Automática

3. [**Projetos Treinamento**](./Projetos%20Treinamento/README.md)
   - Projetos para iniciantes (aplicar arquitetura)

4. [**Meus Simulados** (tópicos avançados)](./Meus%20Simulados/README.md)
   - Simulado RDS/DynamoDB
   - Simulado Confiabilidade e HA
   - Simulado Segurança Avançado
   - Simulados difíceis

5. **Revisão com Anki**
   - Deck: `AWS Solution Architect Associate - SAA-C03 (327 cards).apkg`

**Tempo estimado:** 8-12 semanas (dedicado 5+ horas/semana)

## 📖 Guia de Recursos por Pasta

### 📁 Módulos Re_Start
18 módulos estruturados com progressão clara:
- **Módulos 01-06:** Fundações (Cloud, Redes, Segurança, Bases, Arquitetura, Operações)
- **Módulos 07-10:** Escalabilidade (Ferramentas, Servidores, Escala, Serverless/Contêineres)
- **Módulos 11-16:** Dados e Operações (Bancos, Redes, Armazenamento, Monitoramento, Gerenciamento, Automação)
- **Módulos 17-18:** Avançado (IA, Tópicos Adicionais)

**Como usar:** Leia sequencialmente, de 01 → 18. Cada módulo prepara o próximo.

---

### 🧪 Laboratorios
14 labs práticos, do básico ao avançado:
1. **Introdução a EC2** - Lançar primeira instância
2. **Criar VPC e Servidor** - Networking básico
3. **Introdução a IAM** - Permissões e controle de acesso
4. **Banco de Dados** - RDS/DynamoDB na prática
5. **CLI da AWS** - Automação via linha de comando
6. **Website em S3** - Hosting estático
7. **Escala e Resolução de Nomes** - Route 53 e escalabilidade
8. **Serverless e Contêineres** - Lambda, ECS, Fargate
9-14. **Serviços avançados** - Redes, Armazenamento, Monitoramento

**Como usar:** Faça os labs após cada 2-3 módulos. Cada lab consolida a teoria.

## 🎯 Redirecionamento Profissional

Enquanto você estuda, construa sua carreira cloud:

### Fase 1: Enquanto Estuda (0-4 semanas)
1. **Atualize seu LinkedIn**
   - Adicione habilidades AWS (EC2, VPC, S3, IAM)
   - Siga empresas e profissionais cloud

2. **Comece seu Currículo Cloud**
   - Use template em `Curriculo/`
   - Destaque qualquer experiência com AWS

3. **Prepare Portfólio**
   - GitHub com projetos Cloud (mesmo pequenos)
   - Documente seus labs

### Fase 2: Após Cloud Practitioner (4-8 semanas)
1. **Certificado + LinkedIn**
   - Adicione badge AWS CLF-C02
   - Publique certificado

2. **Busque Oportunidades Iniciais**
   - Cloud Support Associate
   - Junior Cloud Engineer
   - Cloud Administrator

3. **Networking**
   - Comunidades cloud online (Discord, Slack)
   - Meetups técnicos

### Fase 3: Estudando Solutions Architect (3-6 meses)
1. **Certificado SAA-C03**
   - Alto peso no mercado
   - Abre porta para mid-level

2. **Posições Alvo**
   - Solutions Architect Associate
   - Cloud Infrastructure Engineer
   - DevOps Engineer (com Docker/Kubernetes)

3. **Projetos Portfólio**
   - Arquitetura completa multi-tier
   - High availability com multi-AZ
   - Disaster recovery setup
   - CI/CD pipeline

## 💡 Dicas para Sucesso

1. **Consistência > Intensidade**
   - 1-2 horas diárias é melhor que 10 horas no fim de semana

2. **Prática é essencial**
   - Não só leia: faça cada lab, cada simulado

3. **Anki funciona**
   - Dedique 10 min diários. Transformador para retenção.

4. **Aprenda o "porquê"**
   - Não decore respostas. Entenda arquitetura e trade-offs.

5. **Tenha um projeto real**
   - Estude enquanto trabalha em algo prático (mesmo pessoal)

6. **Comunidade é poder**
   - Não estude sozinho. Encontre grupos de estudo.

## ❓ Dúvidas Frequentes

**P: Por onde começo?**
R: Se é iniciante total, faça a "Trilha Iniciante". Se já tem noções, pule para "Cloud Practitioner".

**P: Quanto tempo leva?**
R: Cloud Practitioner: 4-8 semanas (dedicado). SAA: 8-12 semanas após CPT.

**P: Preciso fazer os labs?**
R: SIM. São 70% do aprendizado efetivo.

**P: Qual certificação escolher primeiro?**
R: Cloud Practitioner (CLF-C02) é a base. Depois Solutions Architect (SAA-C03).
