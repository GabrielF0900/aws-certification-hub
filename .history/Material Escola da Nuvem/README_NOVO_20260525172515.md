## 📚 Visão Geral

Este repositório organiza todos os recursos do **Programa AWS RE/START** em módulos objetivos, com foco em leitura progressiva, prática guiada e preparação para certificações AWS. A proposta pública prioriza clareza e consistência para quem está iniciando ou aprofundando em cloud.

| Bloco | O que você encontra |
|---|---|
| **18 Módulos Re_Start** | 155+ PDFs cobrindo desde Cloud Foundations até tópicos avançados |
| **14 Labs Práticos** | Exercícios guiados from básico (EC2) até avançado (CloudFormation) |
| **Simulados** | 19+ simulados temáticos e completos para validar conhecimento |
| **Recursos Anki** | 768 flashcards em 2 decks para revisão espaçada |
| **Guias Profissionais** | Templates de currículo, dicas de carreira e projetos práticos |

## 🚦 Trilhas de Aprendizado

### 1️⃣ **Trilha Iniciante** (0-3 meses)

**Ideal para:** Quem está começando em cloud

**Sequência:**
1. **Módulos 01-06** → Cloud Foundations, Networking, Security, Bases, Architecture, Operations
2. **Labs 01-07** → EC2, VPC, IAM, CLI, S3 websites, Scaling
3. **Meus Simulados** → Questões temáticas de reforço
4. **Anki** → 10 min/dia com flashcards

**Tempo:** 4-8 semanas dedidado 5+ horas/semana

### 2️⃣ **Trilha Cloud Practitioner** (1-4 meses)

**Ideal para:** Preparação certificação CLF-C02

**Sequência:**
1. **Todos os Módulos 01-18** → Progressão completa
2. **Todos os 14 Labs** → Prática consolidada
3. **Meus Simulados** → Todos os 15 questionários
4. **Simulados do Maik** → 4 simulados na reta final
5. **Anki** → Revisão diária 5-10 min

**Tempo:** 6-10 semanas dedicado 5+ horas/semana

### 3️⃣ **Trilha Solutions Architect Associate** (3-6 meses)

**Ideal para:** Evolução para SAA-C03 após CPT

**Sequência:**
1. **Módulos 07-18** (com foco em arquitetura)
2. **Labs 08-14** → Serverless, Databases, Networks, Storage, Monitoring, IaC
3. **Projetos Treinamento** → Aplicar arquitetura em cenários
4. **Anki** → Deck SAA-C03 (327 cards)

**Tempo:** 8-12 semanas dedicado 5+ horas/semana

## 📖 Como Usar Este Material

### 📋 Passo 1: Escolha Sua Trilha
- **Iniciante total?** → Trilha Iniciante
- **Quer certificação CLF-C02?** → Trilha Cloud Practitioner
- **Já tem CPT?** → Trilha Solutions Architect

### 📚 Passo 2: Siga a Sequência
1. Leia o módulo (PDF na pasta **Modulos Re_Start**)
2. Faça anotações e revise
3. Execute o lab correspondente (pasta **Laboratorios**)
4. Resolva questões do simulado temático (pasta **Meus Simulados**)
5. Revise com Anki (10 min/dia)

### 📊 Passo 3: Valide Seu Progresso
- Simulados temáticos no meio do curso
- Simulados completos a cada 2 semanas
- Simulados do Maik na reta final (1 semana antes da prova)

### 🎓 Passo 4: Certifique-se e Evolua
- Faça o exame na Pearson VUE
- Compartilhe certificado no LinkedIn
- Escolha próxima trilha de especialização

## 💡 Dicas para Sucesso

### 📋 Antes de Começar
- [ ] Acesse AWS Free Tier (grátis por 12 meses)
- [ ] Instale o Anki (gratuito) - https://apps.ankiweb.net/
- [ ] Configure seu espaço de estudo
- [ ] Bloqueie 1-2 horas diárias

### 📚 Durante os Estudos
- [ ] Leia PRIMEIRO, depois faça o lab
- [ ] Não decore: ENTENDA os conceitos
- [ ] Faça Anki 10 min/dia (consistência é tudo)
- [ ] Estude em grupo (+ motivação e clareza)
- [ ] Documente seu aprendizado em notas

### 🧪 Prática é Tudo
- [ ] Cada lab deve ser feito com suas mãos
- [ ] Limpe recursos após cada lab (economize $)
- [ ] Tente modificar labs (segredo do aprendizado profundo)
- [ ] Crie arquiteturas simples no papel

### 🎯 Antes da Prova
- [ ] 2 semanas: Simulados completos (Meus Simulados)
- [ ] 7 dias: Revise erros frequentes
- [ ] 3 dias: Simulados do Maik
- [ ] 1 dia: Descanse, não estude!

## ❓ Dúvidas Frequentes

**P: Por onde começo?**
R: Se é iniciante, comece com "Trilha Iniciante". Se já tem noções de cloud, pule para "Trilha Cloud Practitioner".

**P: Quanto tempo leva?**
R: Trilha Iniciante: 4-8 semanas. CPT completo: 6-10 semanas. Dedicado 5+ horas/semana.

**P: Preciso fazer todos os labs?**
R: SIM. Labs são 70% do aprendizado efetivo. Prática hands-on é essencial.

**P: Qual certificação começar?**
R: CLF-C02 (Cloud Practitioner) é a base sólida. Depois evolua para SAA-C03 ou AIF-C01.

**P: Quais são os pré-requisitos?**
R: Nenhum! Este material é feito para quem está começando. Mas básico de redes ajuda.

**P: Posso estudar enquanto trabalho?**
R: Sim. 1-2 horas diárias é suficiente. Consistência > intensidade.

**P: E depois de certificado?**
R: Atualize LinkedIn, busque oportunidades, considere próxima especialização.
